## Audio Profiles
Open **Audio centre → Audio Profiles** and save your current levels or start from a template. Include master volume, microphone and per-app levels. If an app has no active audio session, its level can be applied when the session appears. Restoring respects manual changes.

## Smart Profiles
In **Settings → Automations**, create a rule with a condition and actions. For example, use Focus to turn on Do Not Disturb and switch Companion to the Productivity page. The order of rules determines priority. You can pause them at any time.

## Stopwatch and Focus
Open **Time → Stopwatch** to start timing and record laps. In the Timer tab, start **Focus 25 min** for a session you can use as an automation event.
